# Recherche de véhicules

## Présentation

Ce projet est réalisé dans le cadre de ma formation **Concepteur Développeur Web**.

## Fonctionnalités

- Recherche d'annonces sur jusqu'à 3 sites.
- Sauvegarde des résultats dans un fichier.
- Envoi des annonces par e-mail.
- Enregistrement dans une base de données.

## Développements prévus

Un site web complémentaire permettra de consulter les résultats des recherches enregistrées.
